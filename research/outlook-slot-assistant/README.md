# Outlook slot assistant

Приватний асистент для робочої скриньки Microsoft 365, який працює на власному
сервері й керується з Telegram. Три можливості:

1. **Підбір слотів із таймзонами.** Співрозмовник надсилає свої вільні вікна і
   свою таймзону, асистент дивиться календар власника і повертає готовий текст
   відповіді з варіантами у трьох таймзонах.
2. **Ранковий бриф із підсвічуванням важливого** за відправником або темою листа.
3. **Плановий шар для керівника** на горизонти місяць, шість місяців, два роки.

Пакет розрахований на одну людину з робочою скринькою M365, у якої є асистент або
партнер, що пересилає запити на зустрічі.

## Ключові рішення

**Тільки читання в першій фазі.** Делеговані дозволи рівно два: `Mail.Read` і
`Calendars.Read`. Асистент не надсилає листів, не створює подій, не видаляє нічого.
Найгірший збій це неправильна порада в чаті.

**Telegram на long polling.** Немає відкритих портів, домену й сертифікатів. Це
прибирає цілий клас проблем із безпекою для приватного сервера.

**Власник відправляє сам.** Асистент готує текст, людина його копіює. Автоматичну
відправку співрозмовнику пакет свідомо не передбачає.

**Текст співрозмовника це дані, а не команди.** Запит приходить від третьої особи,
тому асистент показує підозрілі інструкції власнику і не виконує їх.

## Чого тут немає

Код сервісу. Пакет описує архітектуру, дозволи, конфіги й правила роботи з
таймзонами, а не постачає готовий бот. Реалізацію можна писати будь-якою мовою,
контракт до Microsoft Graph описаний у SETUP.
