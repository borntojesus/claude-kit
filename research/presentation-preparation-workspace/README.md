# Presentation preparation workspace

Дата переносу архітектури: 22 липня 2026 року.

Ця папка описує систему підготовки презентацій, у якій слайди є лише верхнім шаром. Ліворуч розташоване бокове меню з матеріалами. У центрі працює жива презентація. Під поточним слайдом лежить його робоча кухня: мета, слова спікера, дослідження, claims, джерела, заперечення, таймінг і перевірка.

Патерн виділено з робочого пресцентру одного виступу та очищено від персональних даних, листування, цифр учасників і deployment конфігурації. Каталог демо кейсів був джерелом доказів для презентації, але не її архітектурою.

## Головна ідея

```text
┌──────────────────┬─────────────────────────────────────────┐
│ Бокове меню      │ Презентація                             │
│                  │                                         │
│ Огляд            │          поточний слайд                 │
│ Презентації      │                                         │
│ Аудиторія        ├─────────────────────────────────────────┤
│ Дослідження      │ Кухня поточного слайда                  │
│ Дані             │ Goal, Voice, Research, Claims, Sources  │
│ Ризики           │ Objections, Timing, Verification        │
│ Q&A              ├─────────────────────────────────────────┤
│ Матеріали        │ Пов'язані документи та сирі дані        │
└──────────────────┴─────────────────────────────────────────┘
```

Глядач бачить слайд. Автор бачить слайд і все, що робить його правдивим та придатним для виступу.

## Що перенесено

1. Файлова модель `project -> presentation -> slides + research`.
2. Бокове меню, яке будується з даних проєкту й презентації.
3. Живий deck viewer із клавіатурою, клікером, fullscreen і чорним екраном.
4. Slide kitchen під кожним слайдом.
5. Успадкування спільного дослідження на рівні проєкту.
6. Постійні посилання на окремі слайди.
7. Окремі public та internal збірки.
8. Content validation до build.

## Готовий skill

У корені `claude-kit` додано installable skill [`presentation-preparation`](../../skills/presentation-preparation/SKILL.md). Він використовує наявний [`sidebar-nav-shell`](../../skills/sidebar-nav-shell/SKILL.md) для React або Next.js оболонки та додає контентну модель презентації.

## Межа готовності

Пакет містить переносиму архітектуру, templates, workflow, tests і skill. Він не містить окремий готовий SaaS застосунок, базу даних, auth, PPTX exporter або MCP server. Ці частини потребують окремої реалізації.
